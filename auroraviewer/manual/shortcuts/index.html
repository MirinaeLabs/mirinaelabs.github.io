키보드 단축키

이동, 배율, 평가처럼 반복되는 작업은 키보드만으로 이어갈 수 있습니다. 아래는 버전 1.6.3의 기본값이며 설정에서 동작별로 바꿀 수 있습니다.

단축키 다시 지정

  1. AuroraViewer 설정을 열고 단축키 페이지로 이동합니다.
  2. 카테고리 또는 검색으로 동작을 찾습니다.
  3. 새 키와 Command, Option, Control, Shift 조합을 기록합니다.
  4. 메뉴 표시와 캔버스 입력에서 새 단축키가 동작하는지 확인합니다.
  5. 문제가 있으면 해당 동작 또는 전체 단축키를 기본값으로 복원합니다.
참고
⌘H처럼 macOS 표준 메뉴와 충돌하는 조합은 의도대로 동작하지 않을 수 있습니다.

명령 검색 팔레트

  1. ⌘⇧P를 눌러 명령 검색 팔레트를 엽니다.
  2. 명령 이름이나 카테고리를 입력합니다.
  3. 표시된 단축키를 확인하거나 Enter로 첫 결과를 실행합니다.
  4. Escape로 닫고 캔버스로 돌아갑니다.
