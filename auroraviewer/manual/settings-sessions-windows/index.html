설정·세션·여러 창

설정은 모든 뷰어에 적용되는 선호값이고, 세션은 각 창의 라이브러리와 선택·검색·캔버스 상태입니다. 두 범위를 구분하면 복원과 여러 창 작업을 예측하기 쉽습니다.

설정 페이지

  • 뷰어: 배율, 안티에일리어싱, 픽셀 그리드, 투명 배경, 유사 이미지, 두 장 보기, 슬라이드쇼, 세션·캐시를 설정합니다.
  • 인터페이스: 앱 언어, 사이드바·평가 도구·오버레이·타이틀 바 표시 방식을 정합니다.
  • 마우스 입력: 휠 탐색·확대, 전체 화면 클릭, 컬러 샘플, ROI 드래그 조합을 바꿉니다.
  • 단축키·외부 앱·기본 앱·지원: 키 동작, 등록 앱 순서, Finder 연결과 도움말을 관리합니다.

마지막 세션 복원

  • 세션에는 소스 그룹, 선택, 검색·정렬·필터, zoom·pan·회전, 비교 슬롯 상태가 포함됩니다.
  • 자동 복원을 켜면 외부 입력 없이 실행할 때 저장된 창을 바로 복원합니다.
  • 자동 복원이 꺼져 있으면 저장된 세션이 있을 때 복원 여부를 묻습니다.
  • Finder에서 파일을 열어 앱을 실행하면 새 입력을 우선하고 이전 세션 bootstrap을 건너뜁니다.
  • 사라졌거나 권한이 없는 파일은 건너뛰고 복원하지 못한 개수를 알립니다.

여러 뷰어 사용

  1. 파일 메뉴에서 빈 새 뷰어를 열거나 현재 선택·라이브러리를 새 뷰어로 보냅니다.
  2. 필요하면 선택한 이미지를 각각 별도 뷰어로 엽니다.
  3. 윈도우 메뉴에서 보이는 뷰어를 격자로 정렬하거나 위치 편집을 시작합니다.
  4. 배치가 마음에 들지 않으면 이전 뷰어 배치로 되돌립니다.
  5. 모든 창의 사이드바를 한 번에 펼치기, 접기, 고정 또는 자동 숨김으로 맞출 수 있습니다.
참고
창 격자 정렬은 보이는 비최소화·비전체화면 뷰어가 2개 이상일 때 사용합니다.

캐시와 로컬 상태

  • 일반 이미지 미리보기, 압축 해제 결과, 중복 분석 결과는 다시 만들 수 있는 로컬 파생 데이터입니다.
  • 종료 시 일반 캐시 전체 삭제를 켜거나 설정에서 즉시 모든 캐시를 비울 수 있습니다.
  • 암호 압축 임시 추출물은 일반 캐시 설정과 관계없이 항상 정리됩니다.
  • 캐시를 비워도 원본 이미지 파일은 삭제되지 않습니다.
