내보내기·자르기·​메타데이터

원본을 그대로 다른 이름으로 저장하는 작업과 픽셀을 다시 인코딩하는 변환 내보내기는 결과가 다릅니다. 목적에 맞는 경로를 먼저 선택하세요.

현재 이미지를 변환해 내보내기

  1. 파일 메뉴에서 현재 이미지 내보내기를 엽니다.
  2. PNG, JPEG, TIFF, HEIC, WebP 중 출력 형식을 선택합니다.
  3. 손실 형식이라면 10–100% 품질을 정합니다.
  4. 자르기, 크기, 메타데이터 정책을 확인합니다.
  5. 저장 위치와 이름을 선택해 내보냅니다.
참고
특정 출력 인코더 제공 여부는 현재 macOS ImageIO 지원에 의존합니다.

자르기와 크기 변경

  • 미리보기 위에서 영역을 그리거나 이동·크기 조절하고, X·Y·가로·세로 픽셀 값을 직접 입력할 수 있습니다.
  • 캔버스에 같은 이미지의 ROI가 있으면 자르기 영역으로 자동 전달됩니다.
  • 크기는 원본, 5–300% 비율, 명시한 가로·세로 픽셀 중 선택합니다.
  • 리사이즈는 표시·공유용 8-bit sRGB 경로이며 고비트·광색역 원본의 보존용 변환은 아닙니다.

메타데이터 정책

  • 유지: 첫 프레임의 원래 ImageIO 속성을 가능한 범위에서 복사합니다.
  • 위치 정보만 제거: 표준 GPS와 EXIF subject location을 제거합니다.
  • 메타데이터 제거: 빈 속성에서 출력에 필요한 최소 값만 다시 설정합니다.
  • 모든 변환 출력은 화면 방향대로 픽셀을 정규화하고 orientation을 1로 기록합니다.
주의
‘위치 정보만 제거’는 알려진 표준 필드를 대상으로 하며 모든 제조사 비공개 메타데이터에서 위치 흔적이 전혀 없음을 보장하는 포렌식 도구는 아닙니다.

원본 저장과 일괄 내보내기

  • 원본 다른 이름으로 저장은 현재 파일의 바이트를 변환 없이 복사합니다.
  • 원본 일괄 내보내기는 선택·그룹·필터 범위의 원본을 대상 폴더로 복사합니다.
  • 같은 이름이 있으면 번호를 붙여 기존 파일을 덮어쓰지 않습니다.
  • 애니메이션의 변환 내보내기는 전체 프레임 변환이 아니라 첫 표시 이미지를 단일 프레임으로 저장합니다.

EXIF 편집

  1. JPEG, TIFF 또는 HEIC 이미지 한 장을 선택합니다.
  2. 이미지 메뉴에서 EXIF 수정을 엽니다.
  3. 설명, 작가, 저작권, 카메라·렌즈, 날짜, 노출 관련 지원 필드를 편집합니다.
  4. 값 형식을 확인하고 저장합니다. 빈 문자열은 해당 키를 제거합니다.
  5. 필요하면 최근 Aurora 작업 실행 취소로 편집 UI에 노출된 이전 값을 되씁니다.
주의
EXIF 실행 취소는 원본 파일 전체의 byte 백업이 아니라 편집한 필드의 이전 값을 되쓰는 동작입니다.
