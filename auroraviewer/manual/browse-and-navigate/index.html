탐색과 이동

큰 라이브러리에서는 현재 위치를 잃지 않고 다음 후보로 넘어가는 것이 중요합니다. AuroraViewer는 선택과 스크롤 위치를 유지하며 목록 변화 뒤에도 같은 파일을 가능한 한 계속 가리킵니다.

이전·다음 이미지로 이동

  1. 캔버스가 활성화된 상태에서 ← 또는 →를 누릅니다.
  2. 멀리 이동하려면 하단 슬라이더의 손잡이를 끌거나 원하는 눈금을 선택합니다.
  3. 특정 항목으로 가려면 사이드바 행이나 썸네일을 선택합니다.
  4. 휠 이동을 선호하면 설정의 마우스 입력에서 휠 탐색과 보조 키를 조정합니다.

여러 항목 선택

  • Command-클릭으로 개별 항목을 더하거나 뺍니다.
  • Shift-클릭으로 기준 항목과 클릭한 항목 사이 범위를 선택합니다.
  • 다중 선택은 비교, 평가·태그 일괄 적용, 이동·복사, 중복 검사 범위로 이어집니다.
  • 파일 작업 전에 선택 개수와 범위를 다시 확인합니다.

그룹으로 방향 유지하기

  • 각 입력 소스는 사이드바 그룹으로 표시되며 접기·펼치기를 지원합니다.
  • 폴더별 그룹과 모든 항목을 합친 단일 목록 사이를 바꿀 수 있습니다.
  • 그룹 순서를 위아래로 옮기거나 목록에서 그룹을 제거할 수 있습니다.
  • 그룹 제거는 원본 파일을 삭제하지 않습니다.

슬라이드쇼로 순서대로 보기

  1. 이동 메뉴에서 슬라이드쇼를 시작합니다.
  2. 필요하면 일시정지하거나 다시 재생합니다.
  3. 설정에서 1–30초 간격과 끝에서 반복할지 정합니다.
  4. 수동 검토로 돌아가려면 슬라이드쇼를 중지합니다.
