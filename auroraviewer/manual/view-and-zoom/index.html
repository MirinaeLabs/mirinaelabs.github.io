확대·이동·보기 모드

사진 전체 구도를 빠르게 확인할 때와 원본 픽셀을 검사할 때 필요한 배율은 다릅니다. 보기 모드를 전환하고 커서 기준 확대와 팬으로 세부를 확인하세요.

배율 모드 선택

  • 창 크기에 맞추기: 이미지 전체가 현재 캔버스 안에 들어오도록 표시합니다.
  • 원본 크기: 소스 픽셀과 화면 point의 기본 1:1 기준으로 봅니다.
  • 200%: 픽셀 구조를 더 가까이 확인하는 지정 배율입니다.
  • 비율 유지: 다음 이미지로 넘어가도 현재 표시 배율을 유지합니다.
동작 기본 키
창 맞춤/원본 전환 ⌘0
창 맞춤 ⌥1
원본 크기 ⌥2
비율 유지 ⌥3
200% ⌘⌥2

확대, 팬, 회전

  1. + 또는 −를 눌러 단계적으로 확대·축소합니다.
  2. 포인터가 있는 지점을 중심으로 확대하려면 설정된 휠 확대 동작을 사용합니다. 기본은 Command-휠입니다.
  3. 확대된 이미지를 드래그하거나 미니맵을 이용해 이동합니다.
  4. ⌘[ 또는 ⌘]로 90도 회전하고 Space로 배율·팬·회전을 초기화합니다.

전체 화면과 클린 뷰

  • ⌘Return은 전체 화면을 전환합니다.
  • ⌥Space는 클린 뷰를 전환해 조작 패널과 오버레이를 최소화합니다.
  • 사이드바, 하단 슬라이더, 미니맵, 히스토그램, EXIF 오버레이는 각각 켜고 끌 수 있습니다.
  • 자동 숨김을 사용하면 포인터 상호작용 중에만 필요한 컨트롤을 볼 수 있습니다.

픽셀과 색을 정확히 보기

  • 안티에일리어싱은 끄기, 균형, 고품질, 최고품질 중 선택할 수 있습니다.
  • 픽셀 그리드는 픽셀 하나가 충분히 크게 보일 때 경계를 표시합니다.
  • 투명 배경은 시스템, 흰색, 회색, 검정, 체커보드 등에서 선택합니다.
  • 큰 이미지는 먼저 화면에 맞는 미리보기를 보여 주고, 상호작용이 멈추면 필요한 세부를 단계적으로 높입니다.
