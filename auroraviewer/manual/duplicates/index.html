중복·유사 이미지 찾기

중복/유사 이미지 찾기는 파일을 자동으로 삭제하지 않습니다. 어디에서 어떤 기준으로 찾을지 정한 뒤 결과를 비교하고, 정리할 파일을 직접 선택하세요.

검색 시작

  1. 전체 라이브러리, 현재 검색·필터 결과, 썸네일 바에서 선택한 이미지 또는 특정 폴더 중 검색할 곳을 정합니다.
  2. 완전 동일, 같은 이미지 추정, 시각 유사, RAW+JPEG 쌍 중 필요한 검사 종류를 선택합니다.
  3. 엄격, 보통, 넓게 중 민감도를 고릅니다.
  4. 검색을 시작하고 진행 상태와 일부 파일에서 발생한 오류를 확인합니다.
  5. 결과 그룹을 열어 각 이미지와 유지 추천 이미지를 비교합니다.

이미지 비교 방식

  • 완전 동일: 파일 내용이 완전히 같은 이미지를 찾습니다.
  • 같은 이미지 추정: 이미지 크기와 픽셀 패턴을 비교해 다시 저장된 유사본을 찾습니다.
  • 시각 유사: Apple Vision으로 구도와 내용이 비슷한 이미지를 찾습니다.
  • RAW+JPEG: 같은 폴더에서 기본 파일명이 같은 카메라 원본과 현상본을 짝지어 봅니다.
참고
‘AI 기반 유사 이미지 분류’는 설정에서 끌 수 있습니다. 민감도를 ‘넓게’로 정하면 결과가 많아져 직접 확인할 이미지도 늘어납니다.

결과 검토와 정리

  • 그룹 종류와 신뢰도, 이미지 수, 예상 절약 용량을 먼저 확인합니다.
  • 유지 추천은 해상도와 파일 크기, RAW 여부를 바탕으로 고른 참고 정보입니다.
  • 뷰어 또는 비교 모드에서 확대해 실제 차이를 확인합니다.
  • 필요하면 별점·태그를 먼저 남긴 뒤 목록 제거, 휴지통, 이동, 복사 중 원하는 작업을 선택합니다.
주의
유지 추천은 파일 품질을 확정하는 판단이 아니며 어떤 파일도 자동으로 삭제하지 않습니다. 휴지통으로 옮기거나 이동하기 전에 원본, 편집본, RAW 파일의 관계를 직접 확인하세요.
