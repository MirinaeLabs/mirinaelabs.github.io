중복·유사 이미지 찾기

중복 검사는 자동 삭제 기능이 아니라 검토 대상을 모으는 도구입니다. 검사 범위와 기준을 정한 뒤 권장 보존본과 근거를 확인하고 실제 파일 작업은 직접 선택하세요.

검사 시작

  1. 전체 라이브러리, 현재 필터 결과, 사이드바 선택 또는 특정 폴더 중 검사 범위를 정합니다.
  2. 완전 동일, 같은 이미지 추정, 시각 유사, RAW+JPEG 쌍 중 필요한 검사 종류를 선택합니다.
  3. 엄격, 보통, 넓게 중 민감도를 고릅니다.
  4. 검사를 시작하고 진행 상태 또는 부분 실패를 확인합니다.
  5. 결과 그룹을 열어 각 항목과 권장 보존본을 비교합니다.

검사 방식 이해

  • 완전 동일: 전체 파일 SHA-256으로 바이트가 같은 파일을 찾습니다.
  • 같은 이미지 추정: 픽셀 크기와 64비트 지각 해시로 재인코딩된 유사본을 좁힙니다.
  • 시각 유사: Apple Vision 특징 거리로 비슷한 구도와 내용을 비교합니다.
  • RAW+JPEG: 같은 폴더에서 기본 파일명이 같은 카메라 원본과 현상본을 짝지어 봅니다.
참고
Vision 기반 분류는 설정에서 끌 수 있습니다. 넓은 민감도는 더 많은 후보를 보여 주므로 직접 확인할 양도 늘어납니다.

결과 검토와 정리

  • 그룹 종류, 신뢰도, 항목 수, 예상 절약 용량을 먼저 확인합니다.
  • 권장 보존본은 해상도, 파일 크기, RAW 여부에 따른 검토 보조입니다.
  • 뷰어 또는 비교 모드에서 확대해 실제 차이를 확인합니다.
  • 필요하면 별점·태그를 먼저 남긴 뒤 목록 제거, 휴지통, 이동, 복사 중 원하는 작업을 선택합니다.
주의
권장 보존본은 파일 품질을 절대적으로 판정하지 않으며 자동 삭제하지 않습니다. 휴지통이나 이동을 실행하기 전에 원본·편집본·RAW 관계를 직접 확인하세요.
