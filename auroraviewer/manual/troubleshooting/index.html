문제 해결과 제한

이미지를 열 수 있는지는 파일 자체의 형식과 macOS 지원, 파일 접근 권한, 압축 파일 제한에 따라 달라질 수 있습니다. 아래 항목을 순서대로 확인해 원인을 찾아보세요.

이미지가 열리지 않을 때

  1. 파일 확장자가 지원하는 파일 형식에 포함되는지 확인합니다.
  2. 같은 형식의 다른 파일이 열리는지 확인해 파일 자체 문제인지 구분합니다.
  3. Finder 또는 macOS 미리보기에서 해당 파일을 읽을 수 있는지 확인합니다.
  4. AI·EPS 같은 문서는 포함 미리보기, Quick Look 또는 선택적 Ghostscript에 따라 결과가 달라질 수 있습니다.
  5. 문제가 계속되면 파일 형식과 macOS·AuroraViewer 버전을 적어 지원 페이지로 제보합니다.

폴더·태그·파일 작업 권한

  1. 권한 안내가 나타나면 작업 대상 파일이 들어 있는 상위 폴더를 선택합니다.
  2. Finder 태그, 이름 변경, 이동처럼 파일을 바꾸는 작업에는 이미지가 들어 있는 폴더의 쓰기 권한이 필요할 수 있습니다.
  3. 파일이 외부에서 이동되거나 삭제되었는지 Finder에서 확인합니다.
  4. 복원된 세션에서 빠진 파일은 위치를 다시 열어 라이브러리에 추가합니다.

압축 파일이 일부만 열릴 때

  • 지원 이미지가 아닌 항목은 추출하지 않습니다.
  • 압축 안의 압축 파일은 재귀적으로 열지 않습니다.
  • 압축 파일이 20,000개 항목, 이미지 한 장당 256MB, 전체 1GB 제한을 넘으면 일부 파일을 열지 못할 수 있습니다.
  • 암호는 3회까지 입력할 수 있습니다. 취소하거나 실패해도 열 수 있는 다른 파일은 계속 불러옵니다.

표시가 느리거나 예상과 다를 때

  • 큰 이미지는 빠른 미리보기를 먼저 보여 준 뒤, 화면이 안정되면 더 선명한 이미지와 현재 보이는 영역을 차례로 준비합니다.
  • GIF·WebP·APNG 애니메이션, 투명 이미지, 픽셀 그리드는 일반 정지 이미지와 표시 방식이 달라 속도 차이가 날 수 있습니다.
  • 캐시 문제가 의심되면 설정에서 모든 캐시 비우기를 실행한 뒤 파일을 다시 엽니다.
  • macOS의 ‘동작 줄이기’를 켜면 빈 라이브러리의 Aurora 효과가 더 느리게 움직입니다.

내보내기·외부 앱 문제

  • 선택한 파일 형식으로 내보낼 수 있는지는 현재 macOS의 ImageIO 지원에 따라 달라집니다.
  • 등록한 외부 앱이 이동되었다면 설정에서 앱을 다시 추가합니다.
  • 기본 이미지 앱은 설정의 ‘기본 앱’에서 파일 형식별로 등록합니다. 등록이 반영되지 않으면 Finder의 ‘정보 가져오기 > 다음으로 열기 > 모두 변경’을 사용합니다.
  • 애니메이션 변환 내보내기는 전체 프레임이 아니라 단일 이미지를 만드는 기능입니다.

문제 제보

  • macOS 버전과 AuroraViewer 버전
  • 문제가 발생한 형식과 파일이 폴더·압축 중 어디에서 열렸는지
  • 문제를 재현하는 가장 짧은 작업 순서
  • 개인정보를 가린 오류 메시지나 화면 캡처
참고
지원 페이지의 GitHub Issues 링크에서 새 제보를 작성할 수 있습니다. 저작권 또는 개인정보가 있는 원본 이미지는 공개 이슈에 첨부하지 마세요.
