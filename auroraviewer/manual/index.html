작업별 설명서

각 페이지에서 기능을 언제 쓰는지, 가장 짧은 사용 순서와 관련 단축키, 알아 둘 제한 사항을 확인할 수 있습니다.

01 시작하기AuroraViewer를 설치하고 첫 라이브러리를 열어 기본 사용법을 익힙니다. → 02 이미지·폴더·압축 열기이미지, 폴더, 압축 파일을 여는 방법과 처리 조건을 확인합니다. → 03 탐색과 이동키보드와 하단 슬라이더, 썸네일 바를 이용해 라이브러리를 빠르게 이동합니다. → 04 확대·이동·보기 모드창 크기에 맞추기, 원본 크기로 보기, 회전과 화면 정보 도구를 사용합니다. → 05 썸네일 바·검색·정렬·필터이미지가 많은 라이브러리에서 원하는 항목만 찾고 한꺼번에 처리합니다. → 06 비교와 두 장 보기이미지를 2~4분할로 비교하거나 이어지는 두 페이지를 함께 봅니다. → 07 평가·태그·파일 정리별점과 선택/제외를 표시하고 Finder 태그와 실제 파일 작업을 구분해 사용합니다. → 08 색상·메타데이터·검사 도구EXIF, 히스토그램, 컬러 픽커, 미니맵과 ROI로 이미지 정보를 확인합니다. → 09 중복·유사 이미지 찾기완전히 같거나 비슷한 이미지와 RAW+JPEG 쌍을 찾아 함께 검토합니다. → 10 내보내기·자르기·​메타데이터원본 복사와 파일 형식 변환의 차이를 알아보고 자르기·크기·메타데이터를 설정합니다. → 11 키보드 단축키기본 단축키를 확인하고 작업 방식에 맞게 다시 지정합니다. → 12 설정·세션·여러 창보기·입력·단축키를 설정하고 열어 둔 작업과 여러 뷰어 창을 관리합니다. → 13 문제 해결과 제한파일 열기, 접근 권한, 압축 파일, 표시 속도, 내보내기 문제를 순서대로 확인합니다. →
