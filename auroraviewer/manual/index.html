All topics

작업별 설명서

각 페이지는 용도, 가장 짧은 실행 순서, 관련 단축키와 중요한 제한을 함께 제공합니다.

01 시작하기설치 후 첫 라이브러리를 열고 기본 검토 흐름을 익힙니다. → 02 이미지·폴더·압축 열기여러 입력 경로와 폴더·압축 파일의 처리 방식을 이해합니다. → 03 탐색과 이동키보드, 슬라이더, 사이드바를 이용해 라이브러리를 빠르게 이동합니다. → 04 확대·이동·보기 모드화면 맞춤, 원본 크기, 회전과 보조 오버레이를 사용합니다. → 05 사이드바·검색·정렬·필터큰 라이브러리에서 원하는 이미지 집합을 좁히고 일괄 작업 범위를 만듭니다. → 06 비교와 두 장 보기후보 이미지를 2–4개 비교하거나 인접한 두 페이지를 함께 봅니다. → 07 평가·태그·파일 정리별점과 Pick/Reject를 기록하고 Finder 태그와 실제 파일 작업을 구분해 사용합니다. → 08 색상·메타데이터·검사 도구EXIF, 히스토그램, 컬러 픽커, 미니맵과 ROI로 이미지 정보를 확인합니다. → 09 중복·유사 이미지 찾기완전 동일, 같은 이미지 추정, 시각 유사, RAW+JPEG 쌍을 찾아 검토합니다. → 10 내보내기·자르기·메타데이터원본 복사와 포맷 변환을 구분하고 자르기·크기·메타데이터 옵션을 설정합니다. → 11 키보드 단축키기본 단축키를 확인하고 작업 방식에 맞게 다시 지정합니다. → 12 설정·세션·여러 창보기·입력·단축키 설정을 조정하고 작업 상태와 여러 뷰어를 관리합니다. → 13 문제 해결과 제한열기, 권한, 압축, 렌더링, 내보내기 문제를 순서대로 점검합니다. →
