# AuroraViewer GitHub Pages

This folder contains the minimal static pages for AuroraViewer App Store submission.

Recommended target repository:

- Repository: `MirinaeLabs/MirinaeLabs.github.io`
- Target path in that repository: `auroraviewer/`
- Support URL: `https://mirinaelabs.github.io/auroraviewer/support/`
- Privacy Policy URL: `https://mirinaelabs.github.io/auroraviewer/privacy/`
- Marketing URL: optional, or `https://mirinaelabs.github.io/auroraviewer/`

Deploy by copying the contents of this folder into the `auroraviewer/` folder of the GitHub Pages repository and pushing the change.
