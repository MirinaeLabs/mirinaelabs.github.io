Product capabilities

보는 도구를 넘어,
고르고 정리하는 뷰어.

AuroraViewer는 원본 파일의 위치를 유지한 채 탐색, 비교, 평가, 태그, 검사와 내보내기를 연결합니다. 아래 기능은 현재 배포 소스와 버전 1.6.3을 기준으로 정리했습니다.

Browse

여러 소스를 한 라이브러리로

개별 이미지, 여러 폴더와 하위 폴더, ZIP·RAR·7z 안의 이미지를 소스별 그룹으로 엽니다. Finder에서 열기와 드래그 앤 드롭도 지원합니다.

  • 이미지·폴더·압축 파일 동시 추가
  • 그룹 접기·펼치기와 순서 변경
  • 중복 URL 제거와 숨김 항목 제외

큰 이미지도 맥락과 세부를 함께

파일명과 확장자를 검색하고 촬영일·수정일·크기·해상도·별점 등으로 정렬합니다. 여러 필터를 조합할 수 있습니다.

Review

평가와 Finder 태그를 원본 곁에

0–5점과 Pick/Reject 상태를 기록하고 Finder 태그를 읽고 씁니다. 다중 선택이나 필터 결과에도 한 번에 적용할 수 있습니다.

  • 키보드 중심 평가
  • Finder 태그 생성·적용·해제
  • 최근 Aurora 작업 실행 취소
자세히 알아보기

Compare

후보를 나란히, 필요한 만큼

2·3·4개 슬롯에 이미지를 배치하고 줌과 팬을 동기화합니다. 만화·스캔에는 두 장 보기와 오른쪽에서 왼쪽 읽기 방향을 사용할 수 있습니다.

  • 드래그 앤 드롭 슬롯 배치
  • 슬롯별 독립 또는 동기화된 이동
  • 애니메이션 재생과 슬라이드쇼
자세히 알아보기

Inspect

색상과 촬영 정보를 더 가까이

포인터 아래 픽셀의 RGBA·HEX·HSB 값을 확대해 보고, EXIF 오버레이에서 카메라와 촬영 정보를 확인합니다.

  • 컬러 인스펙터와 루페
  • 히스토그램·채널 보기
  • JPEG·TIFF·HEIC의 일부 EXIF 필드 편집

Organize

비슷한 이미지를 묶어 검토

파일 해시로 완전 중복을 찾거나 지각 해시와 평균 색으로 유사 이미지를 그룹화합니다. 자동 삭제하지 않고 사용자가 결과를 검토합니다.

  • 전체·선택·필터 결과 범위
  • 유사도 임계값 조절
  • 그룹별 유지 후보 표시

Export

다음 작업에 맞춰 내보내기

선택한 이미지를 변환하거나 원본을 복사·이동합니다. 자르기, 리사이즈, 품질과 메타데이터 정책을 목적에 맞게 정합니다.

  • PNG·JPEG·TIFF·HEIC·WebP
  • 픽셀·퍼센트·긴 변·짧은 변 리사이즈
  • 메타데이터 유지·제거·사용자 선택

Formats

Workspace continuity
