Keyboard shortcuts

Repeated actions such as navigation, zoom, and rating can stay on the keyboard. These are the version 1.6.3 defaults, and each action can be remapped in Settings.

Remap a shortcut

  1. Open AuroraViewer Settings and go to Shortcuts.
  2. Find an action by category or search.
  3. Record a new key and Command, Option, Control, and Shift combination.
  4. Confirm that the new shortcut appears in menus and works in the canvas.
  5. If needed, restore that action or all shortcuts to their defaults.
Note
Combinations that conflict with standard macOS menus, such as Command-H, may not behave as intended.

Command Palette

  1. Press Command-Shift-P to open Command Palette.
  2. Type an action name or category.
  3. Review the displayed shortcut, or press Return to run the first result.
  4. Press Escape to close it and return to the canvas.
