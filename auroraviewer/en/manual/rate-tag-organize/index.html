Rate, tag, and organize files

Ratings, Finder tags, and file moves have different storage and effects. Start with ratings and Pick/Reject for lightweight review, and use Finder tags when the classification should be visible to other Mac apps.

Ratings and Pick/Reject

  1. Select the current image or multiple images in the sidebar.
  2. Press 0–5 to set a rating.
  3. Press P for Pick or X for Reject.
  4. Use filters to narrow the results, or apply the same decision to all current filtered results.
Note
Ratings and Pick/Reject are stored locally by file path in AuroraViewer. They are not written into the image metadata.

Finder color tags

  1. Select the images you want to tag.
  2. Use the top tag controls or Control-1 through Control-7 to toggle color tags.
  3. Use the tag filter to gather images with the same Finder tag.
  4. When clearing tags, confirm the scope before using Clear All Tags.
Note
Finder tags are extended attributes on the file itself. If write permission is missing, you may need to select and approve the containing folder again.

Distinguish Remove from Trash

  • Remove from List: removes the item only from the AuroraViewer library and leaves the source file intact.
  • Delete Image: moves the file to Finder Trash and removes successful items from the library.
  • Undoing a trash operation can succeed only while the original location is available and the trashed item still exists.
  • Images opened from an archive do not directly move or delete the original entry inside that archive.
Caution
Delete Image moves real files to Trash. Always verify the selected images and scope before running it.

Rename, move, and copy

  • Rename preserves the original extension and checks for name collisions and access.
  • Move updates the library path and local review record for successful files.
  • Copy keeps the original in the library and does not provide an automatic delete-the-copy undo.
  • Batch Export Originals adds a number to conflicting names instead of overwriting existing files.
  • Undo Last Aurora Operation keeps up to 30 in-memory actions and is not guaranteed after relaunch.
