AuroraViewer manual

Compare and two-page viewing

Compare mode finds differences between arbitrary candidates. Two-page viewing reads adjacent items in library order. Choose the mode that matches the task.

Compare selected images

  1. Select one to four images in the sidebar.
  2. Turn on Compare mode. A two-, three-, or four-slot layout is chosen for the selection.
  3. Fill empty slots using the slot menu or drag and drop.
  4. Click a slot to activate it before applying ratings or tags.
Note
Selecting one image still opens a two-slot layout so you can add a second candidate immediately.

Synchronize zoom and pan

  1. Enable Sync and manipulate the slot you want to use as the reference.
  2. Zoom or drag; synchronized slots use the same zoom and pan.
  3. Turn on Independent for any slot you want to inspect separately.
  4. Use Reset All Transforms to return every slot to its default state.

Use two-page viewing

  1. Turn on Two-Page View from the Image menu.
  2. Choose left-to-right or right-to-left reading order.
  3. Move through spreads with Left Arrow and Right Arrow.
  4. Turn off Two-Page View to return to single-image viewing.
Note
Two-page viewing works best for sequential files such as comics or scans. Use Compare mode for arbitrary candidates.
