Export, crop, and metadata

Saving an original under another name and re-encoding pixels into another format produce different results. Choose the path that matches your intent.

Export the current image with conversion

  1. Open Export Current Image from the File menu.
  2. Choose PNG, JPEG, TIFF, HEIC, or WebP.
  3. For a lossy format, choose 10–100% quality.
  4. Review crop, size, and metadata policy.
  5. Choose a destination and file name, then export.
Note
Availability of a particular output encoder depends on the ImageIO support in the current macOS version.

Crop and resize

  • Draw, move, and resize the crop on the preview, or enter X, Y, width, and height in pixels.
  • An ROI for the same image is automatically carried into the crop area.
  • Choose original size, a 5–300% scale, or explicit width and height in pixels.
  • Resize uses an 8-bit sRGB path intended for display and sharing, not archival preservation of high-bit-depth or wide-gamut originals.

Metadata policies

  • Keep: copies the first frame's original ImageIO properties where possible.
  • Remove Location: removes standard GPS and EXIF subject-location fields.
  • Strip Metadata: starts with empty properties and writes only values required by the output.
  • Every converted output normalizes pixels to the visible orientation and records orientation as 1.
Caution
Remove Location targets known standard fields. It is not a forensic guarantee that no location trace remains in every manufacturer-private metadata field.

Save originals and batch export

  • Save Original As copies the current file's bytes without conversion.
  • Batch Export Originals copies originals from a selection, group, or filtered result to a destination folder.
  • If a name already exists, a number is added instead of overwriting the file.
  • Converted export of an animation saves the first displayed image as a single frame; it does not convert the whole animation.

Edit EXIF

  1. Select one JPEG, TIFF, or HEIC image.
  2. Open Edit EXIF from the Image menu.
  3. Edit supported description, author, copyright, camera, lens, date, and exposure fields.
  4. Validate the value formats and save. An empty string removes that key.
  5. If needed, use Undo Last Aurora Operation to write back the previous values exposed by the editor.
Caution
EXIF undo writes back the previous editable field values; it is not a byte-for-byte backup of the whole source file.
