Troubleshooting and limitations

Most issues relate to codec support in the file, sandbox access, archive safety limits, or system services available in the current macOS version. Use the checks below to narrow the cause.

When an image does not open

  1. Confirm that the file extension is in the supported input list.
  2. Try another file of the same format to distinguish a file-specific issue.
  3. Check whether Finder or Preview in macOS can read the file.
  4. For documents such as AI or EPS, results can depend on embedded previews, Quick Look, or optional Ghostscript support.
  5. If the issue persists, report it through Support with the file type and macOS and AuroraViewer versions.

Folder, tag, and file-operation permissions

  1. When prompted, select the parent folder that contains the files you are working with.
  2. Operations that write, such as Finder tags, rename, and move, may need broader approval than viewing.
  3. Use Finder to check whether the file was moved or deleted outside AuroraViewer.
  4. For files skipped during session restore, open their current location and add them to the library again.

When an archive opens only partially

  • Entries that are not supported images are not extracted.
  • An archive nested inside another archive is not opened recursively.
  • Items can fail when the archive exceeds 20,000 entries, 256 MB per image, or 1 GB total extraction.
  • Password entry allows up to three attempts. If you cancel or it fails, other usable input continues processing.

When display is slow or unexpected

  • Large images show a lower-cost preview first, then prepare higher quality and visible-region tiles after the view settles.
  • GIF, WebP, and APNG animation, transparent images, and pixel grid use a different rendering path from static opaque images.
  • If cache appears stale, clear all caches in Settings and reopen the file.
  • With Reduce Motion enabled, the empty-library Aurora effect updates less frequently by design.

Export and external-app issues

  • The selected output encoder must be available through ImageIO in the current macOS version.
  • If a registered external app moved, add it again in Settings.
  • Register default image apps by format in Settings > Default App. If registration does not take effect, use Finder > Get Info > Open with > Change All.
  • Converted export of an animation creates one image, not a full multi-frame export.

Report an issue

  • macOS version and AuroraViewer version
  • The affected format and whether it was opened from a folder or archive
  • The shortest steps that reproduce the issue
  • An error message or screenshot with personal information removed
Note
Use the GitHub Issues link on the Support page to create a report. Do not attach source images containing copyrighted or personal information to a public issue.
