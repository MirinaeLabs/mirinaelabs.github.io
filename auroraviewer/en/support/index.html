Quick checks

Check these first

A file will not open

A recognized extension can still fail when file contents or macOS ImageIO and Quick Look support are incompatible. Compare with another file and check for damage.

Folder access stopped working

Moving or renaming a source can invalidate saved access. Open the original folder again and approve the macOS permission prompt.

An archive does not finish

Passwords allow three attempts, with limits of 256 MB per item, 1 GB total, and 20,000 entries. Nested archives are not opened automatically.

I want AuroraViewer as the default

In AuroraViewer Settings > Default App, register the formats you want and select Refresh Status. If registration does not take effect, use Finder > Get Info > Open with > Change All.

Useful context

What to include

  • Your AuroraViewer and macOS versions
  • The steps that produced the problem and the result you expected
  • The file format and input type: individual file, folder, or archive
  • If possible, a redacted screenshot and whether the issue repeats
